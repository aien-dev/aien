# Allen source map (P0, stream `map`)

Status: PROPOSED. Qualification: NOT_RUN. This page is a reading of existing code and records. It runs nothing and qualifies nothing.

Purpose: before P1 writes any code, one page says where each existing Allen part lives, at which commit, who owns it, and what `aien-dev/allen` may import, extend or must never copy. Moving coordination here does not mint a second identity, fork memory or create a new authority (see `docs/OWNERS.md`).

How to read it:

- **Pinned sha** is the full commit read on 2026-10-20 (`git fetch`, then `origin/main`, or the named branch tip). Re-pin before relying on a row.
- **Status** quotes the repository's own words (IMPLEMENTED, TESTED, SPECIFIED, PROPOSED, PARTIAL, FUTURE). `branch-only` means the work is not on the default branch; the branch or pull request is named. Nothing here is written QUALIFIED. The only qualification-style evidence cited is a signed receipt in `aien-dev/aien-receipts`, and its verdict is quoted as found.
- **Allen relation** is `reuse` (use as is), `extend` (the owner adds to it), or `missing` (nothing exists).
- **Import boundary** says what `aien-dev/allen` may import or link, and what it must never copy or re-implement. "Link" means a pinned reference by repository, path and sha. No row allows copying source into this repository.
- Where code and an ADR disagree, the row says so. The code is the evidence.
